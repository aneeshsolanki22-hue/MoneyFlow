# Font System

| Font | Role | Used for |
|------|------|----------|
| **Inter** | Body / Labels | Descriptions, labels, placeholders, body text, chips, secondary text, nav labels, toggle labels |
| **Space Grotesk** | Primary Display | Headlines, balance amounts, CTA buttons, popup titles, category names, income/expense labels, "Hey, User" |
| **Sora** | Analytics Display | Analytics page headings (Month, Chart Title, By Category), amounts, section titles |
| **JetBrains Mono** | Mono / Transactions | Transaction amounts (-₹450, +₹12,000), category names, transaction times (12:30 PM) |
| **Space Mono** | Date Headers | Date headers (TODAY, YESTERDAY) |

## Usage Guide

| Size | Font | Where |
|------|------|-------|
| 42–52px | Space Grotesk | Balance amounts, large display |
| 28–30px | Space Grotesk / Sora | Page titles, month switcher |
| 22–26px | Space Grotesk | Popup titles, "Hey, User" |
| 17–20px | Space Grotesk / Sora | Category breakdown titles, chart titles, settings name |
| 14–16px | Inter / Space Grotesk | Button text, nav labels, category names, amounts |
| 12–13px | Inter / Space Mono | Labels, descriptions, date headers, chips, secondary text |
| 11–12px | Inter | Version, footer, small secondary |
